# projetoA3RogerioOpenGL

## Como enviar as alterações para o GitHub
1. Confirme os arquivos alterados:
   ```bash
   git status
   ```
2. Selecione o que deve ser versionado:
   ```bash
   git add <arquivos-ou-diretórios>
   ```
3. Crie um commit descritivo em português (por exemplo, "Atualiza shaders"):
   ```bash
   git commit -m "Mensagem do commit"
   ```
4. Envie o commit para o branch remoto (substitua `work` se estiver em outro branch):
   ```bash
   git push origin work
   ```
5. Caso use Pull Requests, abra um PR no GitHub a partir do branch enviado para revisão.
